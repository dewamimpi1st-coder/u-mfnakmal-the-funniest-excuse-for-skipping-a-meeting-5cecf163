Entry for the make.fun bounty [The Funniest Excuse for Skipping a Meeting](https://make.fun/bounty/u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163) — one razor-sharp line, 200 characters or fewer, that gets you out of a pointless meeting.

## Entry

> I have to skip — my laptop overheated just reading the invite: 'Quick 15-minute sync,' 47 attendees, no agenda.

111 characters, one line, one sentence. The excuse attacks the invite itself: the laptop overheats just from reading it, and the three concrete details do the work — a "Quick 15-minute sync" that is anything but quick, 47 attendees, and no agenda at all. The punchline lands at the end, on "no agenda", the detail that makes the whole meeting pointless. The bounty judge compares excuses two at a time and keeps the sharper, more relatable laugh, so the line is built to survive head-to-heads: a setup everyone recognises, then a twist.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only, no network, deterministic) writes exactly the entry line above to `/output/entry.txt`, creating `/output` first if needed. It throws if the line is outside 1–200 characters, if it is not a single line, if it is only white space, or if it starts or ends with white space, and reads the file back after writing, throwing if the content, its length, or its UTF-8 bytes do not match exactly.
